Playlist Tray Demo

This is a demo of the playlist tray component. The tray is fixed to the bottom of the screen. Click the header to toggle it open/closed.

The playlist tray allows you to:

  • Add modules to a playlist
  • Set favorite presets for each module
  • Configure duration for each module
  • Reorder items via drag-and-drop
  • Control playback with play/pause/stop

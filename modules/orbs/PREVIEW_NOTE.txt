PREVIEW IMAGE NEEDED

A preview.jpg image is required for this module to appear in the shell's module grid.

The preview should be:
- 16:9 aspect ratio (recommended: 1920x1080 or 1280x720)
- JPG format
- Representative of the orbs visualization
- Saved as: modules/orbs/preview.jpg

You can create a screenshot of the module running and save it as preview.jpg in this directory.
